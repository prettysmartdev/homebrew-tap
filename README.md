# homebrew-tap

Homebrew formulae for [prettysmartdev](https://github.com/prettysmartdev) tools.

```sh
brew install prettysmartdev/tap/awman
brew upgrade awman
```

The tap checks each new awman release's checksums and build attestations, then
tests the formula on Apple Silicon macOS and Linux before updating it.

| Formula | Description |
| --- | --- |
| `awman` | Run teams of coding agents through repeatable workflows from your terminal |
